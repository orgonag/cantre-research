# Staged build plan

## 0 — Rights and research baseline

Inventory this documentation, define the 1% denominator and absolute tolerance,
select an authorized public corridor source and preserve provenance. Record open
questions in RESEARCH.md. Exit: rights/source boundaries clear; unresolved numeric
thresholds are visibly pending and never treated as passes.

## 1 — Independent pure calculation core

Implement projection, polyline cumulative length, qualified anchor bracketing and
milepost interpolation using synthetic geometry. Include units, decreasing MPs,
degenerate geometry and explicit no-result cases. Exit: core acceptance tests pass;
no source-app code or fixtures copied; no UI required.

## 2 — Reproducible public corridor preparation

Parse a bounded public package, audit stable IDs, joins, qualifiers, source dates,
CRS and geometry density; preserve raw separately. Reject name-only subdivision
joins. Emit a documented versioned bundle and provenance manifest. Exit: repeatable
output hashes and audit report; no invented anchors or unsupported coverage claim.

## 3 — Candidate matching

Add spatial indexing, explicit user selection and route/subdivision locks with no
silent switching. Prioritize diamonds and nearby different Class I railways alongside
junction/parallel-track ambiguity with synthetic
and lawful public cases. Compare baseline and continuity strategies without tuning
to private reference outputs. Exit: correct no-result/ambiguous states and documented
thresholds. The preselected-track pilot is not acceptance evidence for this stage.

## 4 — Phone research interface

Add permission handling, fresh/stale fix states, source labels, calculated milepost
and public assets. Test mobile interaction and accessibility. Default to on-device
location processing with no trace upload. Exit: integration and browser tests pass;
no operational assurance language. Local development is not deployment authorization.

## 5 — Independent evaluation

Use authorized recorded fixes and independently established anchors with provenance.
Report coverage, ambiguous/rejected rates, cross-track residual and along-track
milepost error separately. Isolate geometry, anchors, datum and matching effects in
controlled experiments. Exit: documented evidence against agreed metrics, or honest
failure/pending status; do not relabel reference disagreement as accuracy.

## 6 — Rights and release review

Audit dependencies, source/data rights, attribution, location privacy and limitations.
Only after explicit approval choose an open-source licence, public visibility and
hosting. US ingestion needs separate suitable-source validation; LRT remains optional.
No stage authorizes railway access or operational deployment.
